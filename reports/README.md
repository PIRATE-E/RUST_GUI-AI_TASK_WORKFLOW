## 📜 Rules

- Every report follows the `report-protocol` skill structure.
- Reports are teaching documents, not reference manuals.
- No report may use Rust concepts from banned Topics (08+) without flagging them as preview.
- Reports connect Slint concepts to Python equivalents where possible.
- Domain READMEs maintain their own sub-indexes.
